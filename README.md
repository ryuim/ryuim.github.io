現現在の「ムク（MUKU）」に実装されている全機能と動作・反応の仕組みは以下の通りです。すべてローカル環境（Web Audio API・HTML5/Tailwind CSS）で完結しています。

**■ 起動と起床時の演出**

* **お目覚め:** 「ムクを起こす」ボタンを押すと、画面中央にムクの顔が表示されます。
* **パチクリと鳴き声:** 起床と同時に目を2回すばやくまばたきさせ、同時に可愛い鳴き声（ピュッというサイン波）を**2回連続**で発音します。

**■ 環境（センサー）による自律変化**
撫でられていない時、以下の条件に応じて自動で表情や状態が切り替わります（※ムク自身の鳴き声やゴロゴロ音の再生中、および感情変化中はマイクの誤反応を防ぐガードが働きます）。

* **通常:** 静かな環境での基本状態（丸い目）。
* **注目（ビクッとする）:** マイクが一定以上の大きな音（ボリューム70以上）を検知すると、目を大きく見開いて驚き、**同時に鳴き声が1回鳴ります**。3秒経つと自動で通常に戻ります。
* **リラックス:** スマホに充電ケーブルが接続されていると、目を細めて穏やかな表情になります。
* **眠い（省電力）:** バッテリー残量が20%以下、または夜23時〜朝5時の深夜帯になると、目をトロンと閉じかけの色合いになります。

**■ 撫でる（タッチ）による2段階の反応**
画面を指でゴシゴシと撫でると、現在の環境状態を上書きして反応します。

* **1段階目（にっこり）:** 少し（2ストロークほど）撫でると、目が半月型（にっこり笑顔）になり口が開きます。
* **2段階目（喉を鳴らす）:** さらに撫で続けると、**ゴロゴロ音が鳴る直前に可愛い鳴き声が1回鳴り**、その後スピーカーから人間の可聴域限界である超低音（20Hzの鋸歯状波＋LFOの呼吸リズム）で「ぐるる、ぐるる…」とリズミカルに振動し始めます。
* **余韻のある停止:** 指を離して1秒経つと元の状態に戻り、音声はまず呼吸の揺れ（LFO）が1.5秒かけて平坦になり、そのあとマスターボリュームが1秒かけてゆっくりとゼロに向かってフェードアウトし、完全にノイズレスで消えていきます。
