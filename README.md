現在の「ムク（MUKU）」に実装されている全機能と動作仕様の一覧です。今回のバージョンで追加された充電アイコンの自動連動機能も含めて網羅しています。

## 起動と起床時の演出

* **お目覚め:** 「ムクを起こす」ボタンをタップすると起動し、画面中央にムクの顔が表示される。
* **パチクリと鳴き声:** 起床と同時に目を2回すばやくまばたきさせ、同時に可愛い鳴き声（サイン波）が**2回連続**で発音される。

## 環境・センサーによる自律変化

撫でられていない時、周囲の環境やデバイスの状態に応じて自動で表情やアイコンが切り替わる。

* **通常:** 静かな環境での基本状態（丸い目）。
* **注目（ビクッとする）:** マイクが一定以上の大きな音（初期しきい値140、スライダーで50〜255に調整可能）を検知すると、目が大きく見開いて驚き、鳴き声が1回鳴る。3秒後に自動で通常に戻り、連続誤作動を防ぐ8秒間のクールダウン機能も搭載。
* **リラックス（充電中）:** スマホやタブレットに充電ケーブルが接続されていると、自動で目を細めて穏やかな表情になる。
* **充電アイコンの自動表示:** 充電中の状態を検知している間、画面の左上に**充電中のアイコンが自動で表示**される。
* **眠い（省電力・深夜）:** バッテリー残量が20%以下、または夜23時〜朝5時の深夜帯になると、目をトロンと閉じかけの色合いになる。

## 撫でる（タッチ）による反応

画面を指でゴシゴシと撫でると、現在の環境状態を上書きして反応する。

* **1段階目（にっこり）:** 2回以上撫でると、目が半月型（にっこり笑顔）になり口が開く。
* **2段階目（喉を鳴らす）:** **25回以上**撫で続けると、ゴロゴロ音が鳴る直前に可愛い鳴き声が1回鳴り、その後スピーカーから超低音（20Hzの鋸歯状波＋LFOの呼吸リズム）で「ぐるる、ぐるる…」とリズミカルに振動し始める。
* **余韻のある停止:** 指を離して1秒経つと元の状態に戻り、音声は呼吸の揺れ（LFO）が1.5秒かけて平坦になったあと、マスターボリュームが1秒かけてゆっくりゼロに向かってフェードアウトし、完全にノイズレスで消えていく。

## UI・設定機能

* **マイク感度調整:** 画面右上のマイクアイコンをタップすると設定モーダルが開き、スライダー（50〜255、「低（敏感）〜高（鈍感）」の表示）でマイクのしきい値をリアルタイムに調整できる。
* **マルチデバイス対応:** Android 12等の端末や各種ブラウザのビューポート事情を考慮した固定レイアウトにより、アイコンが画面外に見切れることなく確実に操作可能。
