現在の「ムク（MUKU）」の自律的な動作と反応のルールは以下の通りです。すべて外部通信を行わず、端末のローカル機能だけで完結しています。

**■ 起床時の動作**

* **お目覚め:** 「ムクを起こす」ボタンを押すと、目を「パチクリ、パチクリ」と2回すばやくまばたきして起動します。

**■ 環境（センサー）による自律変化**
撫でられていない時は、以下の条件で勝手に表情を変えて過ごします。

* **通常:** 部屋が静かで、特別なイベントがない時の基本状態（丸い目）。
* **注目（ビクッとする）:** マイクが一定の音（拍手や物音など）を拾うと、目を大きく見開いて驚きます。3秒経つとスッと通常に戻ります。
* **リラックス:** スマホに充電ケーブルが繋がれていると、目を細めて口角を少し上げた穏やかな表情になります。
* **眠い（省電力）:** バッテリー残量が20%以下になるか、夜23時〜朝5時の深夜帯になると、目をトロンと閉じかけ、色も暗くなります。

**■ 撫でる（タッチ）による2段階の反応**
画面を指でゴシゴシと撫でると、現在の環境状態を上書きして反応します。

* **1段階目（にっこり）:** 少し（2ストロークほど）撫でると、目が「半月型（にっこり）」になり、口を大きく開けて喜びます。
* **2段階目（喉を鳴らす）:** そのまま撫で続ける（5ストロークほど）と、表情はそのままに、スピーカーから人間の可聴域ギリギリの超低音（20Hz）で「ぐるる、ぐるる…」とリズミカルに喉を鳴らし（振動し）始めます。
* **落ち着く:** 指を離して1秒経つと元の環境状態の表情に戻り、喉を鳴らす音もノイズを出さずに1秒かけてゆっくりと消えていきます。
